## 2026-11-17 · MistralLite 原始 KV 与 SCD 的 APC 全量比较

用户指定两组均由 MistralLite 在 vLLM 开启 APC 完成源 prefill，目标均为 Mistral-7B-v0.1。每题从同一份源页缓存读取原始 post-RoPE BF16 KV。直传组保留 K/V 原值，SCD 组用现有 Patch20/Reuse12 转换。Patch 所需的 xnorm 绑定源 vLLM 的实际页和 slot，APC 命中时从同一个 slot 取回。两组走相同的目标注入路径，导入全 prompt 除末 token 的 KV，由目标计算末 token 并开始生成。目标端关闭 APC，保证两组都实际写入目标页缓存。

每个分片在一张空闲 A800 上运行两个独立 vLLM 进程。两组采用同卡 CUDA IPC 加真实 D2D 拷贝，随后分开计目标页缓存写入。逐题分段计源 prefill、转换、传输、目标准入、KV 写入、写入后生成和收尾。入口统一包含共享的源 prefill；目标耗时含末 prompt token、生成和文本停止判定。先以同篇题的实际 APC 命中、IPC 两端字节校验和目标注入回执验证流程，再按篇章分片运行 3,219 题，用 CMRC2018 官方脚本算 F1 和 EM。
